## Getting the assignments

Clone once, then pull before starting each new assignment:

```bash
git clone git@github.com:csci5942/assignments.git
cd assignments

# before each new assignment
git pull
```

New assignments appear here as new files; existing assignments are occasionally
corrected or clarified in place. **Pull before you start and before you submit.**
Corrections that change what is required are always announced in Slack.

If you keep your work in this clone, do it on your own branch so `git pull` stays
clean:

```bash
git checkout -b my-work
```

Do **not** push your solutions to this repository, and do not fork it publicly.
Publicly visible solutions are an honor-code problem for you and for whoever
copies them.
